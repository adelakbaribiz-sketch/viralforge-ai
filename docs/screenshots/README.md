## Features visible in screenshots

- Dark-first, no light-theme flash (inline `<head>` script)
- Glassmorphism, gradient borders, glow utilities
- Full RTL/LTR support (Persian + Arabic toggle)
- Mobile-first responsive layout
- Accessible (ARIA labels, keyboard nav, prefers-reduced-motion)
- "Optimized for Hook, Retention & Caption" messaging (never "guaranteed virality")
